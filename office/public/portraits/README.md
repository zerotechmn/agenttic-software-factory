# Character portraits for handoff scenes

Drop one PNG per character here: **transparent background**, full body or half body, any size (about 400×750 px works well, like a standing chibi). The figure stands on the dialogue box and rises out of it; the speaker is lit, the listener dimmed.
Missing files show a coloured initials tile instead. No rebuild needed under `forge console`.
